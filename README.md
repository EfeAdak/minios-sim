
# MiniOS-Sim

MiniOS-Sim is a command-line operating systems simulator developed in C11 for the CEN 302 Operating Systems course.

## Project Modules

- Module A: CPU Scheduling
- Module B: Process Synchronization
- Module C: Deadlock Management
- Module D: Memory Management
- Capstone: Integrated Kernel or File System Simulator

## Development Environment

- Ubuntu 24.04 LTS (WSL2)
- GCC 13.3
- GNU Make 4.3
- C11
- POSIX Threads

## Build and Run

```bash
make
./minios
```

To remove compiled files:

```bash
make clean
```
